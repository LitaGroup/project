# 机器人的初始化逻辑



机器人的本质是一个 opencode + 工作目录，它有自身的`AGENTS.md`，也有自身的工作目录：`.opencode`。



## 初始化

当创建一个新的机器人后，本质上是直接更新 AGENTS.md 和 .opencode 工作目录。

### 目录结构

```
- AGENTS.md    机器人的工作基本原则
- .opencode/   opencode自身的目录
- .opencode/skills/   当前机器人的技能
- .opencode/docs/     当前机器人需要的知识文档等信息内容，opencode可以根据自己完成任务的情况，自行更新总结文档到这里
```



### 新建/编辑 机器人页面更新

`角色定义 PROMPT` -> `机器人定义 AGENTS.md`，保存更新后，直接更新到 对应工作目录的 AGENTS.md 中

新增属性：技能，添加技能的时候，可以从`http://gitea.cinta.team/docs/skills` 进行获取筛选 `SKILL.md` 来选择添加，允许添加多个

新增属性：规范，添加规范的时候，可以从 `http://gitea.cinta.team/docs/standard` 获取各目录下的 `README.md`（不包含仓库根目录 README）来选择添加，允许添加多个。选中某个 README 表示同步其所在目录：初始化时会按仓库原始目录结构，把该目录下的全部文档同步到工位 `.opencode/docs`；平台会在 `.opencode/docs/.standards-manifest.json` 记录本次受管文件，取消选择时只清理这些受管文件，不处理机器人自行沉淀的其他 docs 文档。
