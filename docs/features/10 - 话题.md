# 话题（Topic）

> 统一讨论区：灵感、迭代项、知识文章、任务、工单共用一套「主体 → 话题 → 回复」模型。
> 默认消息进主话题；需要独立讨论时新开话题；话题与任务验收状态解耦。

## 1. 数据模型

| 表 | 作用 | 关键字段 |
| --- | --- | --- |
| `discussion_topics` | 话题/主帖 | `subjectType`、`subjectId`、`title`、`content`、`type`、`status`、`tags`、`isDefault`、`blocking`、`author*`、`metadata`、`lastReplyAt` |
| `discussion_replies` | 回复 | `topicId`、`content`、`author*`、`images`、`mentions`、`metadata`、`sourceMessageId`、`status` |
| `discussion_reads` | 个人已读位置 | `topicId`、`userId`、`lastReadReplyId` |
| `discussion_notifications` | 站内通知 | `userId`、`type`、`topicId`、`replyId`、`readAt` |
| `discussion_task_contexts` | 任务当前输出来源话题 | `taskId`、`activeTopicId` |
| `discussion_task_turns` | 任务话题轮次队列 | `taskId`、`topicId`、`content`、`status`、`actorName` |

- `subjectType`：`idea` / `backlog` / `knowledge` / `task` / `ticket`。
- `type`：`content`（内容）/ `question`（问答）/ `system`（验收不通过等平台生成）。
- `status`：`open` / `resolved` / `closed`。
- `tags`：固定「澄清」「建议」+ 自定义文本。
- 无物理外键：主体删除时由应用层清理。

## 2. 交互约定

- 每个主体首次访问时懒创建 `isDefault=true` 的「主话题」。
- 默认发送消息进入主话题的回复；点击「新开话题」才创建独立话题。
- 话题列表按置顶、最后回复时间排序；支持「全部 / 待回答 / 澄清 / 建议」筛选。
- 话题内支持回复、标记已解决、未读计数、SSE 实时刷新。
- 问答话题保存 `metadata.questionId/questions/answers`；手工新建的问答话题自动把标题/正文作为单问题；任务问答答复后恢复任务执行。
- 标签不参与权限，只用于筛选和表达意图。

## 3. 任务集成

- 任务仍然只有一个 opencode 会话；话题只负责消息归属，不创建额外执行会话。
- 多话题同时触发同一任务时进入 `discussion_task_turns` FIFO，同一任务同时只投递一轮；机器人输出按本轮 `topicId` 归位。
- 主话题回复，或在其它话题中 `@` 当前执行机器人，会通过 `TasksService.sendMessage` 投递到任务会话。
- 机器人正文**不会**自动写入话题；执行机器人必须调用 MCP `reply_topic(topicId, content)` 主动答复，平台只同步机器人提问（问答话题）与轮次状态。
- 触发任务时，模型提示词会带上当前话题 ID 和 `reply_topic` 要求；提问答复/验收返工的恢复提示也会带上对应话题 ID。
- 机器人提问同步为 `type=question` 的话题，任务进入「等待中-待反馈」；答复后进入「待继续」。
- 验收与话题解耦：验收不通过由独立按钮触发，并额外生成一个「验收不通过」系统话题，正文为退回原因。
- 历史 `task_messages` 不迁移、不展示；新消息走话题。

## 4. 通知

- 主体有绑定飞书群时，每条主帖/回复发送群卡片（平台 → 飞书单向）。
- `@机器人`：给机器人负责人写站内通知，并按负责人飞书 `openId` 发送私聊卡片。
- 真人机器人被 `@` 后由负责人结合上下文回复；AI 机器人会在该话题下自动回复。
- 问答待回答通知任务需求方用户。
- 回复通知话题作者（有明确用户时）。

## 5. 接口

### REST

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/topics?subjectType=&subjectId=` | 话题清单（含主话题 ID、未读数） |
| `GET` | `/api/topics/:id` | 话题详情 + 最近回复 |
| `POST` | `/api/topics` | 新开话题 |
| `PATCH` | `/api/topics/:id` | 标题/标签/状态/置顶/锁定 |
| `DELETE` | `/api/topics/:id` | 软删除（主话题不可删） |
| `POST` | `/api/topics/:id/replies` | 回复 |
| `POST` | `/api/topics/:id/answer` | 答复问答 |
| `POST` | `/api/topics/:id/read` | 标记已读 |
| `GET` | `/api/topics/notifications` | 我的话题通知 |
| `POST` | `/api/topics/notifications/read` | 标记通知已读 |
| `GET` | `/api/topics/stream?subjectType=&subjectId=` | SSE 实时事件 |

### Markdown（Agent）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/topics.md?subjectType=&subjectId=` | 话题清单 |
| `GET` | `/api/topics/:id.md` | 话题详情 |
| `POST` | `/api/topics/create.md` | 新开话题 |
| `POST` | `/api/topics/:id/reply.md` | 回复 |
| `POST` | `/api/topics/:id/answer.md` | 答复问答 |
| `POST` | `/api/topics/:id/resolve.md` | 标记已解决 |

## 6. 前端

- 通用组件 `frontend/src/components/topics/TopicPanel.tsx`。
- 已接入：灵感详情、迭代项详情「话题」tab、知识文章「话题」弹窗、任务详情「话题」tab、工单详情「话题」tab。
- 支持主话题/其它话题切换、标签筛选、关键词搜索、@机器人、问答答复、未读标记、站内通知入口、置顶（作者/管理员）与 SSE 刷新。

## 7. 边界与后续

- 话题不是独立 AI 会话；多话题同时触发任务时按 `discussion_task_turns` 任务级 FIFO 执行。
- 飞书只做单向通知，不回收群内回复。
- 当前未实现表情回应、置顶排序交互、关注/免打扰、全文语义检索，后续按需补充。
