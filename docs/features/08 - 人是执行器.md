# 人是执行器



我想优化一下整体的逻辑：



1. 系统中，每个真实的用户，都绑定一个机器人，在整个系统中，都是机器人和机器人来交互协作
2. 绑定的这个机器人，它的执行器是是 这个用户，即：它背后的执行器不是 opencode 这种 agent，而是真实的用户
3. 真实的用户，通过操作台，来完成做机器人的后续的操作
4. 操作台：这个操作台根据不同类型的任务，操作的界面不同，界面为：
   1. 导航顶部：操作台，点击后，没有子导航，是一个完整的操作面板
   2. 操作面板分为三部分：
      1. 左侧：任务栏，列出自己需要完成的所有的任务（上面为活动中的，下面为等待中的）
      2. 中间：聊天交互部分
      3. 右侧：任务详情面板，列出这个任务的类型、上下文、日志
