# 技术-项目经理





项目经理的工作流程：



1. 需求澄清：与需求方进行需求不明确的确认，补充信息，产出：功能清单（FEATURES.md）
2. 方案设计：建立`技术方案` 工单，填写：需求背景、原始资料、功能清单 来完成方案设计
3. 技术开发：根据方案内容，建立开发任务，请具体的开发人员完成代码开发和自测，完成在测试环境的部署
4. 测试回归：建立`需求测试` 工单，填写：需求背景、原始资料、功能清单、技术方案 以及 测试环境的访问地址，提出测试工单，并根据反馈的缺陷，建立 BUG修复任务，完成代码修复
5. 上线发布：建立`上线发布` 工单，申请代码、数据库、配置等上线
