# 日间主题与 beUI 对话工作台

2026-10-28；已批准方案的前端实施定义。分支 `ui-design-update`。

## 范围

仅修改前端呈现、交互视图和 design。保留 assistant-ui 运行时、原请求与 SSE、会话绑定、发送限制、原问答提交和任务状态规则。任务看板保持原布局，只适配日间主题。

## 日间视觉

画布 `#F5F7FB`，卡片 `#FFFFFF`，正文 `#172033`，边框 `#E2E8F0`；主要操作蓝色。状态文字使用较深角色色，实心危险/次要按钮局部采用白色文字。保留菜单图标色、兔子头像、四芒星 AI 标记。大数字转轮采用轻量节奏：基础时长280ms、每位10ms错峰、额外滚动一圈后落到原目标值，稳定后静止；各位置总耗时均比此前缩短一半以上。卡片采用固定材质与稳定阴影，悬停保留普通颜色、边框和按压反馈；移除指针高光、卡片边缘扫光、按钮表面扫光和状态文字渐变扫光。等待/验收任务卡仅保留普通悬停反馈，进行中 Gemini 彩环保持。

仅当前轮回复使用状态光效，历史助手回复使用中性边框。当前回复使用共享 ResponseSurface：运行时复用任务列表 BorderGlow 的 Gemini 彩环和稳定错峰相位；待确认以 `#D99A00` 细边优先呈现，完成以 `#10B981` 细边呈现。进入待确认与完成时，边框及外发光各闪烁3次，每次720ms，随后保留对应颜色的静态柔光；不同动画名称确保从待确认切换到完成时再次播放。过渡250ms，错误沿用错误状态。所有状态保持相同 DOM 与内边距，正文不闪烁、不旋转、不因换状态重建。

## beUI 适配

- 数字翻滚仅用于任务看板和任务概览顶部的6个大号统计值，入场与数值变化时执行；小徽标、括号计数和明细数字直接更新。
- Todo List：展示接口原有最近待办、状态和完成数。按内容与重复序号生成渲染 key。无真实百分比时省略进度。完成后可折叠，保留最近清单的会话级含义。
- Agent Activity：呈现已有 reasoning；最新文本在有限高度内向上跟随，手动阅读历史时暂停跟随，用户折叠选择优先。
- Approval Card：沿用全部问题同时展示、单选/多选、自由输入、统一提交与跳过；待回答停靠在输入框上方，与输入框左右对齐；采用一致的白色底，标题和提交区固定，问题内容独立滚动，回执默认折叠。
- Streaming Response：承接原 Markdown/Mermaid 内容，保留真实流式更新；不添加点赞、模型切换或其他新入口。
- 工具记录：仅使用任务对话已有 tools；最近三项动态上移，已有更早记录可展开。调试接口缺少工具/技能明细，因此不显示技能调用名。

组件源码适配现有 Framer Motion 与 Appica 图标，未引入新的产品依赖。来源与 MIT 声明见 frontend/THIRD_PARTY_NOTICES.md。持续动效沿用用户既有要求。

## 消息视图与追问

原始消息快照保持不变。只读投影按用户消息分轮、以问题 ID 去重，将待回答问题放入 dock；已回答/跳过/失效回执放在同轮最终答复之前。任务消息再限定 taskId 与发送者，未知归属回执保留原位置。

提交失败保留选择、输入和错误提示；问题仍以服务端状态为准。机器人调试页完成后继续通过原输入框和原会话追问，任务详情保持主分支原发送规则。合并 `ac49bd2` 后，调试页 idle 时仍可回答真实 pending 问题；任务详情按主分支“待反馈且属于当前任务”的规则作答。禁用提示使用“暂不可回答”，不会把活跃任务标为已结束。

## 响应式

列表筛选区使用[统一 Toolbar 规范](./filter-toolbar.md)：独立白色控件、40px高度、10px间距，按工具栏自身宽度换行；保留原搜索、选项和筛选行为。

对话工作台可用宽度达到 1040px 时采用聊天 + 288px 最近待办栏。其余采用单栏，上方是受限高度的最近待办。输入与确认区位于聊天消息滚动区外；确认区按对话容器高度限定并独立滚动；窄屏页头保持同一行，小屏同时保留可阅读的聊天记录。短屏待确认状态压缩既有页头、最近待办摘要和输入区的留白，优先保证问题与至少一个完整选项可读，同时保留64px以上聊天记录。长代码和表格在消息内部滚动。
