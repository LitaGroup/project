# 短窗口任务确认区修复

2026-10-28；`ui-design-update`。

仅调整 `daylight-conversation.css` 中任务对话的布局。消息区保留至少 64px；底部确认、待反馈事项、输入及操作区在实际 thread 剩余高度内可收缩，超出部分独立滚动。现有确认卡字段滚动、卡片集合滚动、问题选择和操作条件保留。机器人调试、任务看板、请求、SSE 和业务状态处理未修改。

原问题通过实际前端构建和只读 Docker fixtures 复现：1280×720 的面板底部约 687px，操作按钮却落到 882px；1440×800 面板底部约 767px，按钮落到 890px。修复后底部区域受面板约束，滚动或键盘聚焦即可完整显示操作。
