# AI 对话界面

## 当前方向

延续 Dashboard 5 的深色、紧凑和清晰层级，将机器人调试整理为统一的对话工作台。科技感来自精密的身份标记、真实运行状态的局部流光，以及聚焦、展开和 hover 的细腻反馈。页面保持专业、协调，正文阅读区安静。

用户确认的边界：只改 UI，任务看板卡片、光圈和布局保持现状，共享 Logo 与机器人默认头像按最新明确要求更新，业务逻辑、原有操作和文字保持，代码仅作本地 UI 提交，不推送。沿用既有 worktree，最终分支为 `ui-design-update`。

## 布局与材质

- 调试页使用一个整体面板。身份栏、会话区、待办区通过细分隔线衔接，减少重复边框和投影。
- 身份栏保留机器人名称、执行器、模型、会话信息及原重置操作；缩小头像周围的装饰，模型信息使用等宽小字。
- 正文按统一阅读宽度排版，头像、名称、思考过程和回复形成稳定对齐。思考面板保持原展开/收起行为。
- 输入框采用独立的浅浮层，聚焦时呈现连续彩色细边；运行时仅保留较淡的边缘活动。
- 宽屏对话与待办并排；窄屏上下排列，待办获得明确高度，长内容在原滚动区域内阅读。手机身份与原操作自然分行。

## AI 活动表达

- 用户新增指定品牌：使用 www-lita-cool-original/public/pwa-512x512.png 的 512px 原始兔子图标，平台 Logo 和机器人默认头像共用一份本地资源，兔子右上角加精细 AI 四芒星图形。原有上传头像优先及加载失败 fallback 机制保持。头像不加描边、外框或套圈。原创 AiEnergy 只在原有 running 状态下，于头像背后绘制低亮度的蓝紫青氛围光；空闲时隐藏光层。
- 仅工作中头像的右上四芒星采用10秒节奏：慢启、加速旋转五圈、减速停住，随后静止3.2秒再循环。只复用原 running/working 状态，由 CSS 控制速度，不新增设置、计时器或业务逻辑。空闲头像和平台 Logo 静止。
- 原有“回复中”和“思考中”配活动波形；正文左侧细流线、正在执行的工具底线和实际 in_progress 待办共同表达活动。
- 运行光效集中在身份、思考、工具和输入边缘，不给整块正文加彩色外框或大面积泛光，不生成进度、指标、消息或额外入口。
- 按用户要求持续播放动效，不读取系统减少动态效果。

## 实现边界与验证

WorkerDebugPage、TaskChatPanel 只调整展示 JSX、装饰组件和现有状态的 data 属性。AiEnergy/AiWaveform 为 aria-hidden、pointer-events:none 的 SVG/CSS 装饰，无 hooks、事件、网络、计时或新增依赖。SurfaceEffects 保留原被动指针 effect，仅扩展现有会话表面的样式匹配。

API、SSE、assistant-ui runtime、消息转换、hooks、事件、禁用条件、权限、提问、回复、发送和重置保持。验证覆盖指定的 /tasks/workers/1/debug 入口、空闲/运行/问答状态、六个屏幕尺寸、交互命中与实际动画变化，并就地更新截图及报告。

正式设计、来源、许可、当前截图和可复现验证脚本保留；本任务的临时截图、快照、脚本、构建和缓存验证后清理。
