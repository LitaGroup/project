# 响应式适配记录

本轮仅调整非任务页面布局，任务区沿用已确认效果，全部修改保留在原 worktree，按最终授权归入本地 UI/design 提交。

- 主区按实际可用宽度响应；筛选组换行，窄屏标题、操作与分页有独立空间。
- 表格保留全部列与操作，在自身区域横向滚动，能到达最后一列；整页保持在视口内。
- 项目、缺陷与运行详情在窄内容区上下排列，宽屏保留左右布局；知识目录与文章标题按内容宽度重排。
- 设置长路径、个人资料、APP模拟器面板和概览卡片允许收缩、换行；终端保留可读高度。
- 原有弹窗适配小屏与短屏；分支/提测字段换行，正文可滚动，底部操作保持可达。
- APIPOST 接口文档的独立目录/详情布局同样适配；接口搜索、选择、参数与响应表格保持原有行为。有效示例已用于只读预览的 `/documents/4`。
- 知识文章的原生 Crepe 主题接入现有暗色角色，修复黑字落在暗底上的问题，不改变编辑器行为。

44个页面/状态 × 6尺寸，共264个布局样本完成检查；整页/主区溢出、控件遮挡或裁切、过窄输入和弹窗越界均为0；全部表格末列可滚到。类型检查、生产构建、lint和UI范围审查通过。
