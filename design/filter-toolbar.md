# 列表筛选栏

2026-10-28；统一任务概览、所有任务、项目、检查、用例、导出、文档、资源、节点、提交、定时任务、缺陷、APP、脚本库、仓库及用户等18个列表页的共享 Toolbar 呈现。

移除工具栏外框、内边距和渐变，搜索框与筛选控件分别使用单层白色表面、细边框和轻阴影。控件高度40px、间距10px、圆角沿用角色 token。搜索框带装饰性搜索图标，下拉显示单向箭头；悬停与键盘焦点使用稳定的边框和柔光反馈。

桌面搜索框宽320px，其余控件保留原有宽度。按工具栏自己的可用宽度适配：不足768px时搜索框独占一行；不足480px时筛选控件均匀换行。长选项保留原截断，任务数量在窄屏独立换行。

样式集中在 `frontend/src/styles/filter-toolbar.css`。移除旧的工具栏零散规则，旧表单与按钮材质明确排除 Toolbar；工具栏外的控件保持原样。布局只选中真实的输入包装、筛选按钮和分组，不影响 Select 的隐藏表单输入。

全部 TSX、状态、请求、选项、回调、清空、键盘焦点顺序与筛选规则不变。任务看板的布局、卡片、彩环、数字与数据处理保持。

验证与关键截图见 [浏览器报告](./filter-toolbar-verification.json)。浏览器使用隔离虚构数据；无业务写操作。临时脚本、测量日志和构建产物验证后清理，正式报告与当前截图保留。
